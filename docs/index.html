    ⚙️ Réglages

    🚀 Mise en route (à faire une fois)
    1. Crée une clé GitHub « fine-grained » (github.com → Settings → Developer settings → Personal access tokens) pour le dépôt buzz-insolite, droits Actions et Contents en « Read and write ». Colle-la ci-dessous.
    2. Dans Buffer, relie le compte TikTok de la chaîne, puis écris son nom dans « Compte TikTok » ci-dessous et touche « Tester Buffer ».
    3. Choisis le mode de publication et les heures, puis « Enregistrer les réglages ».

    🔑 Connexion à GitHub (sur cet appareil)

    🏪 Ma chaîne : logos et descriptif

    📲 Appli sur le téléphone (Android)

    1. Sur le téléphone, ouvre tiranno06.github.io/buzz-insolite dans Chrome.
    2. Touche « 📲 Installer l'application » en haut (ou menu ⋮ → « Installer l'application » / « Ajouter à l'écran d'accueil »).
    3. Pour ne pas retaper la clé GitHub : touche ci-dessous « Montrer le code », puis scanne-le avec l'appareil photo du téléphone.

    Appui long sur l'icône : raccourcis 🔥 Buzz, ➕ Créer, 🎬 Vidéos. L'appli s'ouvre même sans réseau (dernières données gardées).
